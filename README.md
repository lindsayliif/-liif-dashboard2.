# LIIF Dashboard

Starter version of the Lindsay Investment Intelligence Framework dashboard.

## Deploy to Vercel

1. Upload all files and the `app` folder to the GitHub repository.
2. Commit the changes.
3. Return to Vercel.
4. Import the GitHub repository.
5. Leave the framework preset as Next.js and root directory as `/`.
6. Click Deploy.

This version uses sample data and does not connect to a broker account.
